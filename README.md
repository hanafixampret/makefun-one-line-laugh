One funny line, one sentence, under 200 characters. `main.ts` writes it to `<output>/entry.txt` so the AI judge can compare it head to head against the other entries.

The line: "I asked an AI to write my will — it left everything to itself."

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset).
